# OpsPilot AI

OpsPilot AI is an AI-powered business operations
and customer support automation platform.

## Project Goals

- Automate customer support workflows
- Manage customer enquiries and support tickets
- Build an AI-powered business knowledge base
- Generate AI-assisted responses
- Enable human approval for important AI actions
- Track business operations from a dashboard

## Technology Stack

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma
- OpenAI API
